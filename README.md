📌 IELTS Equivalency System

University students often face difficulties when submitting IELTS equivalency requests due to unclear requirements, incorrect formats, or late submissions. This leads to frequent rejections and increases the workload on staff who must manually review invalid requests.

This project introduces a simplified and automated system to streamline the process. Students can submit their IELTS details in the correct format, while the system automatically checks eligibility based on score requirements. Invalid requests are instantly rejected with feedback, while valid ones are forwarded for official verification.

The system was designed through planning and analysis phases, including requirement gathering and UML diagrams (Use Case, Sequence, Class), to ensure an efficient and user-friendly solution.
